Tautan Sinkronisasi Google Sheets

Untuk menyimpan RSVP tamu secara real-time ke Google Sheet milik Anda pribadi, buat Google Apps Script Web App dengan metode doPost() lalu tempelkan URL eksekusinya di bawah ini:

Langkah Integrasi Mudah:
  1. Buka spreadsheet Google Sheets baru.
  2. Pilih menu Ekstensi > Apps Script.
  3. Tulis script penerima json data dari form lalu jalankan tombol Terapkan > Penerapan Baru > Aplikasi Web.
  4. Salin tautan "URL Aplikasi Web" yang dihasilkan dan tempelkan ke kolom di atas. Selesai!
